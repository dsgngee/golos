# Copywriting: Removing AI-Sounding Copy

Copy is as strong a "sameness" tell as gradients and stock illustrations. This covers marketing/section copy (headlines, CTAs, body copy) — for UI microcopy (button labels, error/empty states), see `frontend-design`'s writing section instead.

## The 5 Copy Principles

1. **Don't Make Me Think** (Steve Krug) — aim for System-1, not System-2 reading. If understanding a line takes real mental effort, cut it.
2. **Name the pain first** (Daniel Priestley's marketing framework) — lead with the problem the reader recognizes, before the solution.
3. **One ask, one thought, per screen/section** — a single clear point and a single CTA per section, not several competing ones.
4. **Concrete beats abstract** — "5 minutes on the train" lands harder than "5 minutes wherever you are"; give the reader something they can picture.
5. **Action-specific CTAs beat generic ones** — "Start free" or "Start your first lesson" beats a bare "Get started."

## Banned-Word / AI-Tell Checklist

Flag and rewrite around words/phrases that read as AI-generated by default: *unlock, elevate, seamless, seamlessly, revolutionize, leverage, robust, cutting-edge, delve, tapestry, supercharge, empower, game-changer, in today's fast-paced world, whether you're X or Y, it's not just about X, it's about Y*. Also watch for a telltale over-uniform em-dash/rhythm pattern across sentences — vary sentence length and structure the way real edited copy does.

## Competitor Benchmarking

Before finalizing copy, look at the top handful of real competitors in the same niche (`WebFetch`/`WebSearch`) and note what their highest-converting-looking copy does differently from generic/weak examples — borrow the underlying technique, not their actual sentences.

## Optional: Second-Model Humanizer Pass

A second, non-Claude model can be used as an extra pass specifically to reduce recognizable "Claude-esque" phrasing, since any single model's writing style becomes more detectable the more it's used. This is optional and external:
- Only use it if the user already has that model/API access configured.
- Never hardcode a specific model name or version as a requirement — treat it purely as "a second model, if available."
- If unavailable, the checklist above still does most of the work alone — skip this step cleanly rather than blocking on it.

## Output

Copy is judged as part of the gold-standard loop (see `gold-standard-loop.md`) per section — pass/fail against these principles and the banned-word list — not cleaned up as a disconnected, one-off pass at the end.
